# Code of Conduct

## Our standard

We want this project to be a focused, respectful place to discuss Agent workflows, documentation, and security. Participants should be constructive, assume good faith, and keep feedback tied to the work.

## Expected behavior

- Be respectful and specific.
- Welcome different levels of experience.
- Separate people from ideas and evidence from assumptions.
- Disclose security concerns privately when possible.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without consent.
- Deliberately introducing malicious instructions, credentials, or unsafe code.
- Disruptive spam or automated activity.

## Enforcement

Report conduct concerns to the repository maintainer through a private GitHub channel. Security vulnerabilities belong in the process described in [`SECURITY.md`](SECURITY.md), not in a public issue.
